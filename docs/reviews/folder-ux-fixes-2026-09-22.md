# 평가 폴더 중심 UX 수정 기록

2026-09-22 · Sequence Control Tower 0.12.14

## 반영한 작업 원칙

평가 폴더가 기본 작업 범위다. 로그별 수동 판정과 폴더 전체 규칙 적용을 구분하고, 결과·결과 정리·원문을 오가도 현재 범위를 유지한다. 검색 범위, 상세 규칙 조건, 폴더 비교, 여러 종류의 내보내기, 차트 선택 기능은 유지한다. 기존 다크 워크벤치 안에서 작업 버튼과 상태를 정리했다.

이전부터 있던 로컬 변경을 보존했다. 원격 기준은 `main` / `origin/main`의 `f021c69ead30a3a91128950d2a509f835a21bb17`이며, 이전 진단에서 최신 상태로 동기화했다. 이번 변경은 로컬 작업본에 반영했다.

## 수정 내용

| 문제 | 반영한 동작 |
| --- | --- |
| 적용 완료 뒤 적용·편집 버튼 소실 | 완료 여부로 버튼을 숨기지 않는다. 새 검색 뒤 다시 적용할 수 있고 실행 중에는 중복 저장을 막는다. |
| 같은 ID의 규칙을 편집해도 이전 결과가 유효함 | 출현 횟수·순서·matcher 등 실제 규칙 조건을 비교한다. 영향을 받는 이전 판정은 재검사 상태로 바꾸고 최신 규칙을 복원한다. |
| 삭제한 규칙의 충돌/미일치 결과가 남음 | 마지막 배치를 기준으로 무효화하며 오래된 PASS/FAIL이나 충돌 배지를 되살리지 않는다. |
| 해제 범위가 불명확함 | `이 폴더에서 해제`와 `프로젝트에서 삭제`를 구분한다. 마지막 규칙까지 해제할 수 있고 다른 폴더 및 수동 판정은 유지한다. |
| 수동 판정을 취소할 수 없음 | 취소 revision을 저장하고 폴더를 재검사한다. 과거 renderer ID와 Agent ID가 함께 쓰인 동일 로그는 한 번의 저장으로 취소한다. |
| 프로젝트 전환 도중 저장 결과가 섞임 | 저장 큐가 요청을 시작한 프로젝트와 전환 세대를 유지한다. 이전 프로젝트의 완료 응답이 현재 프로젝트를 덮어쓰지 않는다. |
| Agent 실패 원인이 사라짐 | 중지·실패 원인과 `재시도`를 유지한다. 비동기 대화·평가 저장의 완료 응답은 시작한 범위를 확인한다. |
| 파일 검사 실패가 0건처럼 표시됨 | 소스별 진행·성공·실패·응답 누락을 구분한다. 실패 결과를 정상 완료로 캐시하지 않고 재검사를 제공한다. 선택한 폴더의 미완료 검사 동안 관련 내보내기와 표 분석을 비활성화한다. |
| 일부 설정만 저장됨 | 표/내보내기 구성과 연관 평가 하네스를 프로젝트의 단일 원자적 저장으로 묶는다. 규칙의 보조 캐시 실패가 영구 저장 성공을 실패로 바꾸지 않는다. |
| 창이 좁으면 검색·하단 버튼이 잘림 | 검색창 폭 배분을 조정하고 추가 검색 범위는 `…` 메뉴로 옮긴다. 기존 단축키를 유지한다. |
| 화면 이동/설정 저장으로 편집이 초기화됨 | 필터·축·차트·선택·내보내기 열의 세션 초안을 프로젝트와 폴더별로 유지한다. 폴더 비교도 화면 이동과 데이터 갱신에 유지한다. |
| 필터 0건에서 필터 자체가 사라짐 | 필터와 초기화 버튼을 계속 표시한다. |
| 미확인 셀에서 원문을 열 수 없음 | 판정 결과 표의 미확인·제외 로그도 선택할 수 있다. 해당 개수를 표시하며 PASS/FAIL 분모에는 포함하지 않는다. |
| 내보낼 범위와 마지막 동작이 모호함 | CSV 버튼에 대상 개수를 표시하고 숨겨진 선택도 해제할 수 있게 한다. 미리보기에는 선택한 모든 열을 표시하며 `CSV 저장`/`TSV 복사`로 실행한다. |
| 확대 상태가 불명확하거나 선택 시 초기화됨 | 항목이 많은 차트에 범위 막대와 `전체 보기`를 표시한다. 일반 휠은 스크롤로 사용하고 Ctrl+휠로 확대한다. 선택만 바뀌면 확대 범위를 유지한다. 차트 초기화/재생성 오류를 처리하고 차트 오류를 화면 전체로 전파하지 않는다. |

## 검증

- `npm run typecheck`: 통과.
- `npm test`: **683 passed, 3 skipped** / 85개 파일 통과, 1개 파일 건너뜀.
- `npm run build`: Electron main/preload/renderer 빌드 통과.
- `npm run docs:build`: 한국어 매뉴얼 빌드 통과.
- `git diff --check`: 통과.
- 저장소 회귀 테스트: 동일 ID 조건 변경, 규칙 삭제 뒤 충돌 제거, 수동 판정 취소 및 재시작, 과거 ID 동시 취소, 마지막 규칙 해제와 형제 폴더 독립성, A→B→A 저장 큐, 실패/누락 검사 상태, 단일 트랜잭션 구성 저장, 미확인 셀 분모 및 선택, 차트 초기화/확대 복원을 검증했다.
- 렌더링 테스트: 저장된 하네스가 없어도 검사 실패·재검사와 내보내기 비활성화가 표시되는지 확인했다.
- 브라우저 합성 로그 조작: 1100×680과 1280×800에서 검색·판정·적용·새 검색, 규칙 해제, 수동 판정 취소, 폴더 전환 후 원문 복귀, 0건 필터 복구, 필터/열 초안 복원, 비교 모드 유지, 선택 CSV 미리보기, 차트 전환과 셀 선택을 확인했다.

실제 사용자 로그·Electron 사용자 저장소·LLM 연결 설정은 변경하지 않았다. Windows 설치 패키지 실행, 실제 외부 LLM 장애, 실제 디스크 장애는 이번 검증 범위에 포함하지 않았다. 저장 실패·경합은 임시 저장소 및 제어된 테스트 입력으로 검증했다.

## 이후 작업의 기준

새 기능에도 같은 기준을 적용한다: 현재 평가 폴더 표시, 수동 판정 보존, 변경된 규칙의 재검사, 실패 원인과 복구 동작 유지, 편집 초안의 범위 유지, 집계와 내보내기 대상 일치. 화면 설명을 늘리기보다 현재 상태에서 실행할 수 있는 동작을 안정적으로 제공한다.
