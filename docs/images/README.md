# 사용자 매뉴얼 이미지

현재 빌드의 실제 화면을 1920×1080 PNG로 캡처합니다. 고객사명, 사내 URL, API key, 개인 경로는 포함하지 않습니다.

| 파일 | 용도 |
|---|---|
| `manual-lw-00-overview.png` | 로그 목록, 원문, 판정 영역 |
| `manual-lw-01-rule.png` | 검색 근거 선택과 규칙 저장 |
| `manual-lw-02-exceptions.png` | 일괄 판정 예외 검토 |
| `manual-lw-05-results.png` | 결과표와 CSV/TSV 내보내기 |
| `manual-lw-06-patterns.png` | 결과 분포와 조건별 결과 |
| `manual-wf-01-pass.png` | PASS 판정 예제 |
| `manual-wf-02-system-halt.png` | SYSTEM_HALT 판정 예제 |
| `manual-wf-03-decision-revision.png` | 판정 revision 저장 |
| `manual-wf-04-rerun-export.png` | 일괄 판정 후 결과를 필터링하고 CSV/TSV로 내보내는 화면 |
| `manual-llm-settings.png` | LLM 연결과 호출 제한 |

## 캡처 규격

- 1920×1080 PNG
- 실제 앱 화면과 demo data 사용
- 브라우저, 디버거, 개인 경로 제외
- API key와 사내 endpoint 제외
- 텍스트와 주요 상태가 읽히는 배율 유지
- UI가 변경되면 같은 화면 크기로 다시 캡처
