# Sequence Control Tower 0.12.0

- 같은 평가 폴더에서는 로그 검색, 결과, 결과 정리 화면을 이동해도 하나의 Agent 대화를 이어갑니다.
- 다른 평가 폴더는 별도 분석 맥락으로 분리하고, 여러 폴더 선택은 프로젝트 비교로 처리합니다.
- Agent가 현재 결과 정리 기준에 맞는 축, 집계, 시각화를 제안하며 적용 전 미리보기와 되돌리기를 제공합니다.
- DQ, BL, Channel, Sub Channel, Bank Group, Bank 등 실제 Fail address event를 조건별 결과와 분리해 분석합니다.
- QC·MTK 부팅, RT, 4-Corner, Frequency, SKEW·Sample Screening, TM Side Effect, 장문 Halt 페르소나를 검증했습니다.
- GitHub Actions 중복 실행을 제거하고 설치본 Release는 명시적인 수동 실행 또는 로컬 직접 업로드로 제한했습니다.

## 0.11.0

- 결과 정리를 교차표, Heatmap, 세로·가로 막대, PASS/FAIL 구성·비율, 조건 변화, 건수와 비율로 전환할 수 있습니다.
- 조건별 결과, 불량 집중 위치, TM 개선 비교, 주파수 경향, 4-Corner 비교를 시작점으로 제공하며 축과 계산 기준은 계속 수정할 수 있습니다.
- 표와 차트가 같은 선택 로그를 공유하고, 선택한 조건 또는 전체 분석 보기를 Native Agent가 로컬 도구로 다시 검증합니다.
- 현재 분석 보기를 프로젝트에 저장하고 표 CSV, 원본 CSV, 선택 로그 CSV, 시각화 PNG로 공유할 수 있습니다.
- 결과 지표를 파일 수, Sample 수, Grid 수, PASS/FAIL 파일, FAIL률로 구분했습니다.

## 0.10.1

- 7,600~9,100줄 SoC 로그에서 Ctrl+F 전체 일치 개수를 유지하고 500개 단위로 끝까지 이동할 수 있습니다.
- 최근 검색 기록과 엔지니어가 확정한 판정 절차를 분리해 Agent가 올바른 맥락으로 사용합니다.
- 가로·세로 항목을 최대 3단계까지 추가·이동하고 `FAIL률`과 합계를 확인할 수 있습니다.
- `공유`에서 Excel 붙여넣기, 현재 표 CSV, Spotfire용 원본 CSV를 선택할 수 있습니다.
- 평가 이력을 불량 검출·재현, 개선 조건 검증, 불량 경향 확인의 수평 흐름으로 표시합니다.
- 질문 대기 또는 제안 검토 중인 평가 Agent 세션을 앱 재실행 후 복원합니다.
- 느린 LLM 분석을 백그라운드 실행으로 변경했습니다.
- Agent의 결과·평가 이력 정리 진행 상태를 즉시 표시합니다.
- 화면을 이동하거나 Agent 패널을 닫아도 실행 중인 분석 세션을 유지합니다.
- 기능 중심 한국어 매뉴얼을 새로 작성했습니다.
- 최신 화면 캡처와 온라인 매뉴얼 배포 구성을 추가했습니다.
