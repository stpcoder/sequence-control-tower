# Sequence Control Tower 0.12.8

- 첫 판정과 규칙 설정에서 동일한 검색 조건 UI를 사용합니다.
- 첫 판정에서 고른 검색 조건과 순서를 다음 단계에 그대로 유지합니다.
- Agent 검토가 없는 환경에서도 `Enter`로 실행한 검색을 규칙 조건으로 자동 선택합니다.
- `다음`과 `건너뛰기`로 평가 목적 저장 여부만 결정하고 검색 조건을 다시 선택하지 않습니다.

## 0.12.7

- 검색 입력 중간값은 저장하지 않고 `Enter`로 실행한 검색만 기록합니다.
- 기존 버전의 `A → AB → ABC` 형태 검색 기록은 마지막 검색어 하나로 정리합니다.
- `검색 절차 저장`에서 선택한 검색과 순서를 `판정 규칙`에 그대로 설정합니다.
- 판정 규칙에서 검색 기록을 개별 또는 전체 삭제할 수 있습니다.
- 규칙의 저장 범위와 적용 범위를 `프로젝트 규칙`, `폴더 적용`으로 구분했습니다.

## 0.12.6

- 구버전 데모의 `LPDDR6_XIAOMI_...` 파일명을 제거하고 실제 평가용 positional 파일명으로 교체했습니다.
- 기존 V1~V3 데모 프로젝트는 앱 시작 시 보관 처리하고, 오래된 생성 폴더만 안전하게 정리합니다.
- 자재명을 `DHCST-89`, `CHAE-1`, `DHBCT-4`, `BCT-7`, `RTN-21`처럼 서로 다른 형식으로 구성했습니다.
- 같은 `CHAE-25` 자재로 HH·CH·HL·CL 4-Corner 평가를 추가했습니다. HH/CH는 HVDD, HL/CL은 LVDD이며 Hot/Cold 조건을 정확히 조합합니다.

## 0.12.5

- 앱 내장 데모 로그와 장문 QA 로그 58개의 파일명을 실제 평가용 underscore 규격으로 통일했습니다.
- 파일명에서 실장기 채널, SoC, 평가번호, 온도, 전압, ECC, 사용자 조건, 주파수, 자재, 평가 Step과 결과를 분리합니다.
- `COM` 다음 토큰을 자재/Sample 식별자로 읽으므로 `DHCST-89`, `CHAE-1`, `DHBCT-4`처럼 서로 다른 사내 명명 방식을 그대로 사용할 수 있습니다.
- 160자를 넘는 긴 평가 파일명도 끝의 자재·Step·결과가 잘리지 않도록 보존합니다.
- `Ch8` 실장기 채널과 `DRAMCH0` 불량 주소 Channel을 별도 항목으로 처리합니다.

## 0.12.4

- 규칙을 저장하면 현재 평가의 기존 규칙에 누적하고 결과를 즉시 적용합니다.
- 새 규칙은 `규칙 저장`만 누르면 현재 평가에 자동 적용되며 기존 규칙은 유지됩니다.
- 저장 규칙 목록은 `사용`과 `사용 중` 상태만 표시하고 `추가`, `다시 분류`, revision 문구를 제거했습니다.
- 규칙 팝업을 적용 상태·조건·수정·삭제 중심의 간결한 목록으로 정리했습니다.
- 예외 로그에서 새 규칙을 만들면 같은 평가 폴더의 기존 규칙과 함께 전체 로그를 다시 판정합니다.
- 규칙 조건 순서를 안정적으로 재정렬하고 적용 실패 후 다시 시도할 수 있습니다.
- 모든 페이지에서 동일한 `Agent에게 묻기` 진입 버튼을 사용합니다.
- Agent는 선택 로그를 우선하고 최대 32개 로그 참조를 로컬 도구로 검사해 느린 사내 LLM의 초기 분석 부담을 줄입니다.

## 0.12.0

- 같은 평가 폴더에서는 로그 검색, 결과, 결과 정리 화면을 이동해도 하나의 Agent 대화를 이어갑니다.
- 다른 평가 폴더는 별도 분석 맥락으로 분리하고, 여러 폴더 선택은 프로젝트 비교로 처리합니다.
- Agent가 현재 결과 정리 기준에 맞는 축, 집계, 시각화를 제안하며 적용 전 미리보기와 되돌리기를 제공합니다.
- DQ, BL, Channel, Sub Channel, Bank Group, Bank 등 실제 Fail address event를 조건별 결과와 분리해 분석합니다.
- QC·MTK 부팅, RT, 4-Corner, Frequency, SKEW·Sample Screening, TM Side Effect, 장문 Halt 페르소나를 검증했습니다.
- GitHub Actions 중복 실행을 제거하고 설치본 Release는 명시적인 수동 실행 또는 로컬 직접 업로드로 제한했습니다.

## 0.11.0

- 결과 정리를 교차표, Heatmap, 세로·가로 막대, PASS/FAIL 구성·비율, 조건 변화, 건수와 비율로 전환할 수 있습니다.
- 조건별 결과, 불량 집중 위치, TM 개선 비교, 주파수 경향, 4-Corner 비교를 시작점으로 제공하며 축과 계산 기준은 계속 수정할 수 있습니다.
- 표와 차트가 같은 선택 로그를 공유하고, 선택한 조건 또는 전체 분석 보기를 Native Agent가 로컬 도구로 다시 검증합니다.
- 현재 분석 보기를 프로젝트에 저장하고 표 CSV, 원본 CSV, 선택 로그 CSV, 시각화 PNG로 공유할 수 있습니다.
- 결과 지표를 파일 수, Sample 수, Grid 수, PASS/FAIL 파일, FAIL률로 구분했습니다.

- 화면을 이동하거나 Agent 패널을 닫아도 실행 중인 분석 세션을 유지합니다.
- 기능 중심 한국어 매뉴얼을 새로 작성했습니다.
