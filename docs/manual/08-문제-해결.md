# 문제 해결

## Agent 분석이 진행되지 않는 경우

1. Agent 패널의 실행 상태를 확인합니다.
2. `분석 중`이면 화면을 이동해도 작업이 계속됩니다.
3. `다시 시도`가 표시되면 눌러 같은 세션을 재개합니다.
4. 설정에서 API 주소, 모델 ID, 인증, RPM, TPM, 응답 제한 시간을 확인합니다.

대화 기록에서 이전 세션을 다시 열 수 있습니다. 로컬 도구 결과는 LLM 재시도 전에 유지됩니다.

## 로그가 보이지 않는 경우

- 선택한 폴더와 하위 폴더에 `.log` 파일이 있는지 확인합니다.
- 현재 프로젝트가 맞는지 확인합니다.
- 프로젝트 메뉴에서 연결 폴더 경로를 확인합니다.

## 검색 결과로 이동하지 않는 경우

- 검색어를 입력한 뒤 `Enter`를 누릅니다.
- 정규식, 대소문자, 단어 단위 옵션을 확인합니다.
- 검색 범위가 현재 파일, 현재 평가, 열린 파일, 전체 프로젝트 중 어디인지 확인합니다.

## revision 충돌

`최신 revision` 오류가 표시되면 프로젝트를 다시 불러옵니다. Agent 저장은 최신 프로젝트를 한 번 다시 읽고 저장을 재시도합니다. 계속 실패하면 변경 내용을 확인한 뒤 다시 저장합니다.

## 설치 차단

Windows SmartScreen 또는 macOS Gatekeeper가 표시되면 파일 hash와 배포 출처를 확인하고 회사 보안 정책을 따릅니다.

## 데이터 복구

원본 `.log` 파일은 수정하지 않습니다. 프로젝트 metadata가 손상되면 앱이 손상 파일을 별도 이름으로 보존하고 새 저장소를 만듭니다.
