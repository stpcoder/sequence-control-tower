# v0.8 평가 이력과 Agent

`평가 이력`은 프로젝트의 평가 조건, 불량 가설, 평가 노드, 연결 로그 근거를 함께 관리하는 화면입니다.

## 평가 이력 시작

1. 왼쪽 메뉴에서 `평가 이력`을 엽니다.
2. `프로젝트 조건`을 펼쳐 제품, SKU, 고객, 대상 장치, 밀도, 정격 전압을 입력합니다.
3. `조건 저장`을 눌러 프로젝트에 저장합니다.

조건 입력은 저장 전까지 화면의 임시 초안으로 유지됩니다. 프로젝트를 다시 열거나 저장된 조건이 바뀌면 초안도 최신 조건으로 바뀝니다.

## 가설과 평가 추가

1. `불량 가설`에 이름과 근거 메모를 입력합니다.
2. 출처를 `AI 제안` 또는 `엔지니어 확인`으로 고르고 `추가`를 누릅니다.
3. `새 평가`에 평가 이름을 입력합니다.
4. 필요하면 가설, 부모 평가, 브랜치 또는 이슈, 판정 상태를 고릅니다.
5. 조건을 입력하고 `로그 근거 연결`에서 로그를 선택합니다.
6. `평가 추가`를 누릅니다.

입력할 수 있는 LPDDR 조건은 SKU, Lot, Sample, BL, DQ, Channel, Bank, Bank group, Pattern, MHz, 온도, VDD, Skew, Mode입니다. 부모 평가는 조건을 이어받을 수 있으며, 새 평가의 값이 우선합니다.

평가 점은 계보에서 선택할 수 있습니다. 선택한 평가에는 브랜치, 근거 수, 실패율, 조건, Pattern, 주요 DQ가 표시됩니다. 선택한 평가에 연결된 로그는 `열기`로 다시 로그 화면에서 확인합니다.

로그가 없으면 `로그` 화면에서 폴더를 연결하고 가져온 뒤 평가 이력으로 돌아옵니다. 평가가 없으면 오른쪽에서 불량 가설 또는 첫 평가를 추가합니다.

## 반복 불량 경향

`반복 불량 경향`은 저장된 근거에서 DQ, BL, Pattern, Channel, Bank, 주파수, 온도, VDD, Skew 값을 결정적으로 집계합니다. 각 행은 실패 건수, 근거 건수, 실패율, `AI 제안` 또는 `엔지니어 확인` 출처를 보여줍니다.

## 내보내기와 AI 맥락

- `CSV 내보내기`는 프로젝트, 가설, 평가, 근거, 모든 LPDDR 조건, `sourceIds`, 기존 `logRef`를 한 행씩 저장합니다.
- `AI 맥락 복사`는 평가 계보와 반복 불량 경향을 짧은 Markdown으로 클립보드에 복사합니다. Codex, Claude, MCP 클라이언트에 붙여 넣을 수 있습니다. 이 기능은 MCP 서버를 실행하지 않습니다.

## Agent 사용

Agent 패널은 현재 로그를 우선으로 분석합니다. 프로젝트 경향을 함께 볼 수 있으며, 부족한 정보 중 영향이 큰 항목만 질문합니다. 분석 한 번에는 프로젝트 소스를 최대 32개까지 사용합니다.

6,000~7,000줄 로그 원문 전체를 보내지 않습니다. 필요한 검색 결과와 줄 범위만 대상으로 확인합니다. 응답이 느리거나 실패하면 상태를 확인한 뒤 다시 시도할 수 있습니다.

Agent의 진행 중 세션은 앱 프로세스 메모리에만 있습니다. 앱을 종료하면 진행 중 세션은 남지 않습니다. `확인하고 저장`으로 확정한 프로젝트 평가 이력과 근거는 프로젝트에 저장됩니다. 후보는 확인 전까지 프로젝트 이력에 반영되지 않습니다.
