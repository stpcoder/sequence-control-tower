# 프로젝트 관리와 폴더 연결

Sequence Control Tower v0.7에서는 상단의 현재 프로젝트 이름을 눌러 프로젝트를 전환합니다. 프로젝트는 이름과 설명, 연결 폴더, 장비 별칭·템플릿 revision pin·Export preset을 함께 관리하는 작업 단위입니다.

## 새 프로젝트 · 설정 재사용 · 폴더 추가

상단 프로젝트 이름에서 `새 프로젝트`를 선택합니다. 이름과 짧은 목적을 입력한 뒤 `다음`으로 이동합니다. 다음 화면에서 `Sample`, `온도`, `Mode`, `Grid`, `PASS/FAIL`, `Reboot/Halt` 중 추출하거나 결정할 항목을 고르고, 필요하면 직접 입력합니다. 마지막 화면에서 `빈 프로젝트` 또는 기존 프로젝트를 골라 `설정 재사용`을 선택합니다. 재사용되는 것은 onboarding 답변, 장비 profile, template pin, Export preset이며 폴더·artifact·결과는 복사되지 않습니다.

생성 뒤 표시되는 한 가지 다음 작업은 `폴더 추가`입니다. 폴더를 고르면 Mini Agent가 실제 파일명을 바탕으로 가설을 세우고 제한된 검색·줄 범위·정보 확인 도구를 호출합니다. LLM 응답이 느리거나 timeout이 발생해도 대기 상태를 표시하며 로컬 분석은 계속됩니다. 프로젝트 이름을 눌러 기존 프로젝트를 불러오거나, `프로젝트 고급 설정`을 펼쳐 이름·목적·추출 항목과 장비·템플릿·Export preset을 수정할 수 있습니다.

## 폴더 연결

`폴더 추가`는 Electron main process의 폴더 선택기를 사용합니다. 선택한 경로는 main process의 canonical path로만 보관되며 renderer와 화면에는 폴더명과 상대 파일명만 전달됩니다. 프로젝트를 열 때 연결된 `available` 폴더의 로그가 ArtifactService로 다시 가져와 Workbench 파일 목록에 연결됩니다.

연결 폴더가 사라졌거나 접근 권한이 없으면 해당 폴더만 `없음` 또는 `권한 없음`으로 표시됩니다. 다른 폴더의 파일은 계속 열립니다. `재검증`으로 상태를 다시 확인하고, 연결을 해제할 때는 폴더 행의 해제 아이콘을 사용합니다.

기존 Workbench의 `로그 폴더 열기`도 계속 사용할 수 있습니다. 이 방식은 현재 Workbench에 직접 가져오며 프로젝트 폴더 목록에는 추가하지 않습니다.

## 전환 중 안전성

프로젝트 전환에는 generation guard가 적용되어 이전 프로젝트의 늦게 도착한 비동기 응답이 새 프로젝트 화면을 덮어쓰지 않습니다. 폴더 일부가 실패한 경우에도 성공한 폴더는 먼저 표시하고, 실패 개수와 상태를 상단 관리창에 남깁니다.

## Mini Agent

1. 로그를 선택하고 `Agent 열기` 또는 `⌘/Ctrl J`를 누릅니다.
2. `분석 시작`을 누릅니다. 질문이 표시되면 선택지를 누르거나 `짧은 메시지 입력`에 내용을 입력하고 전송합니다.
3. 후보 결과는 `확인하고 저장`을 눌러야만 현재 revision에 저장됩니다. `거절` 또는 `닫기`는 저장하지 않습니다.
4. 프로젝트나 artifact가 없으면 `분석 시작`을 사용할 수 없습니다. `취소`는 실행 중인 분석을 중지합니다.
