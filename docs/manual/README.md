# Sequence Control Tower 매뉴얼

현재 제품의 핵심 작업만 안내합니다. 버전별 과거 매뉴얼은 제거했습니다.

1. [빠른 시작](01-빠른-시작.md) — 프로젝트 생성, 여러 폴더 등록, 로그 확인
2. [로그 분석과 규칙](02-로그-분석-규칙.md) — 검색, 판정, 엔지니어 행동 학습
3. [Agent 네이티브 분석](03-Agent-네이티브-분석.md) — Agent 능력, 질문법, 도구, OpenCode 하네스
4. [결과와 평가 이력](04-결과-평가-이력.md) — 결과 검토, N × M 정리, 평가 문맥 축적
5. [LLM·OpenCode 설정](05-LLM-OpenCode-설정.md) — OpenAI-compatible API, 호출 제한, 보안
6. [설치와 문제 해결](06-설치-문제-해결.md) — Windows/macOS 설치, 오류 조치

## 기본 작업 순서

`프로젝트 선택` → `로그 폴더 열기` → `검색 및 판정` → `분석 절차 확인` → `Agent 질문` → `결과 정리` → `평가 이력 저장`

원본 `.log` 파일은 항상 읽기 전용입니다. 규칙, 판정, 대화, 평가 이력은 프로젝트 데이터로 별도 저장됩니다.
