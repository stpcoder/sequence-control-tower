## 시작

1. 운영체제에 맞는 설치 문서를 확인합니다.
2. [로그 분석 작업](00-log-workbench.md)에서 기본 조작을 확인합니다.
3. [실무 예제](01-practical-workflows.md)에서 판정별 절차를 확인합니다.
4. 필요한 경우 [LLM 연결](05-settings.md)을 설정합니다.

주요 화면은 `로그`, `결과표`, `패턴`, `설정`입니다.

## 상태

- `후보`: 파일명, 로그, 로컬 규칙이 생성한 미확정 값
- `승인`: 엔지니어가 확인한 metadata 값
- `확정`: 엔지니어가 저장한 결과 판정
- `검토 필요`: 규칙 충돌, 근거 누락, 새 파일 내용 등 확인이 필요한 상태
- `UNKNOWN`: 현재 규칙과 근거로 판정할 수 없는 상태

## 확인 사항

- LLM 연결이 없어도 폴더 가져오기, 검색, 규칙 저장, 일괄 판정을 사용할 수 있습니다.
- 동일한 내용의 파일은 원문 저장 공간을 공유하며, 각 파일 출처는 별도 행으로 유지됩니다.
- 예상과 다른 결과는 예외 사유와 근거 줄을 확인한 후 규칙을 수정합니다.
- 회사 로그, API key, 장비 인증 정보가 포함된 화면을 외부에 공유하지 마세요.
