# Sequence Control Tower v0.9.2

v0.9.1의 콘솔 입력 학습, 대용량 LPDDR6 샘플과 Agent UI 변경을 포함합니다.

## 추가 안정화

- Vertex 인증은 Application Default Credentials를 우선 사용합니다.
- ADC가 없으면 현재 활성화된 `gcloud auth` 계정으로 자동 전환합니다.
- access token은 파일에 저장하지 않고 35분 동안 프로세스 메모리에만 유지합니다.
- macOS 실호출에서 `google/gemini-2.5-flash` Chat Completions 응답을 확인했습니다.

상세 기능과 안전 경계는 [v0.9.1 릴리스 노트](90-v0.9.1-release-notes.md)를 참고하세요.
