# Sequence Control Tower v0.9.3

화면 밀도와 Agent 대화 흐름을 로그 워크벤치 기준으로 정리한 버전입니다.

## 화면 정리

- 분석 규칙의 선택과 세부 조건을 한 행씩 표시합니다.
- 이번 분석과 Agent 선택지는 세로 목록으로 표시합니다.
- 로그 목록 상단은 `로그 폴더 열기`와 전체 검색만 남겼습니다.
- 로그 줄 번호 여백을 줄였습니다.
- 결과와 결과 정리, 평가 이력의 상단 제목을 같은 스타일로 통일했습니다.

## Agent

- 프로젝트 대화를 기본으로 사용합니다.
- 질문 입력창에서 `/`를 입력해 특정 로그를 지정합니다.
- Markdown 제목, 목록, 굵은 글씨와 코드를 렌더링합니다.
- 사용한 근거는 해당 답변 바로 앞에 한 번만 표시합니다.
- 대화 기록과 새 대화는 입력창 아래 아이콘으로 제공합니다.

## 평가 이력

- 평가 이력은 근거, 실패율, 조건, Pattern과 주요 DQ만 표시합니다.
- 자연어 평가 메모를 Agent 질문으로 바로 전달합니다.
- 직접 입력은 접힌 상세 메뉴에서 사용할 수 있습니다.
- 화면 표기는 `SKEW`로 통일했습니다.
