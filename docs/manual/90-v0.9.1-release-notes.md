# Sequence Control Tower v0.9.1

## 주요 변경

- UEFI, Qualcomm/MediaTek Bootloader, OS 콘솔 입력 명령을 장비 출력과 분리
- `@PASS`, `@FAIL`, training fail, reboot, halt, fast fail을 판정 근거로 별도 유지
- 모호한 `#`/`$` 프롬프트를 엔지니어에게 한 번 확인하고 프로젝트 규칙으로 저장
- 입력 명령만 Sequence signature와 RT 동일 Sequence 판정에 사용
- Agent 대화·질문·답변·도구 근거와 Ctrl-F/정규식 검색 기록 영구 보관
- 7,000줄 이상 잡음 로그 9개를 생성하는 LPDDR6 Xiaomi 샘플 프로젝트
- Vertex OpenAI-compatible endpoint에서 macOS `gcloud` ADC token 자동 갱신
- Agent 메시지의 반복 역할명과 backend 문구를 제거한 간결한 대화 UI

## 안전 경계

- 로그 전체를 LLM에 전송하지 않습니다.
- 원본 장비 출력은 로컬 검색과 판정에 남지만 Sequence 명령으로 저장하지 않습니다.
- Vertex access token은 설정 파일과 대화에 저장하지 않습니다.
- 모호한 프롬프트 규칙과 명령 목적은 엔지니어 답변 이후에만 프로젝트 기억으로 확정합니다.

## 검증

- 입력/출력/status 분류, 모호한 prompt 재사용, RT signature, Agent 질문·저장 테스트
- 대용량 샘플 9개 import와 각 파일 7,000줄 이상 확인
- Vertex ADC 자동 인증 cache와 OpenAI-compatible Bearer 전송 테스트
- 전체 typecheck, tests, production build, macOS Universal 패키지
