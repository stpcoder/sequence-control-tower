# v0.7 빠른 시작

v0.7에서는 프로젝트별로 추출 항목과 연결 폴더를 관리하고, 로그를 검색·판정한 뒤 결과를 저장하고 내보낼 수 있습니다. 폴더 읽기, 검색, 파싱, 결과 집계, 추세, N × M 그리드, CSV/TSV 내보내기는 로컬 기능입니다. `Agent 열기`와 `AI 패턴 검토`처럼 사용자가 원할 때 실행하는 기능은 선택한 LLM 연결을 사용할 수 있습니다.

## 추가된 기능

- 상단의 현재 프로젝트 이름에서 프로젝트 라이브러리를 열고 `새 프로젝트`를 만들 수 있습니다. 초기화 화면에서 이름과 목적을 입력하고, `무엇을 추출·결정할까요?`에서 `Sample`, `온도`, `Mode`, `Grid`, `PASS/FAIL`, `Reboot/Halt` 또는 `직접 입력 (선택)`을 고릅니다. 기존 설정은 `기존 설정 재사용…`으로 가져옵니다.
- 프로젝트마다 `폴더 추가`로 폴더를 하나씩 연결할 수 있습니다. 연결 상태는 `연결됨`, `없음`, `권한 없음`으로 표시되며 `재검증`으로 다시 확인합니다.
- `로그` 화면은 로그 목록, 원문, 판정의 세 작업 영역입니다. `로그 목록 너비 조절`과 `판정 패널 너비 조절`을 드래그해 폭을 바꿉니다. 열린 파일은 `열린 로그` 탭에 남습니다.
- 검색은 `현재 로그`, `열린 탭`, `전체 로그` 범위를 제공합니다. 결과를 눌러 해당 파일과 줄로 이동할 수 있습니다.
- `Evaluation Agent`는 선택한 파일을 대상으로 제한된 검색·줄 범위·정보 확인을 수행합니다. 후보는 사람이 확인한 뒤에만 저장됩니다.
- `결과 정리`에는 현재 범위의 추세 요약과 `N × M 패턴 그리드`가 있습니다. 행축·열축, 집계값, 필터를 정해 `레이아웃 저장`으로 현재 프로젝트에 저장합니다.

## 한 번의 작업 순서

1. 상단 프로젝트 이름을 누릅니다. 새 작업이면 `새 프로젝트` → 프로젝트 이름과 `짧은 목적 (선택)` 입력 → `다음` → 원하는 추출·결정 항목 선택 → `다음` → `빈 프로젝트` 또는 `기존 설정 재사용…` 선택 → `프로젝트 만들기` 순서로 진행합니다. 기존 작업은 프로젝트 목록에서 이름을 누릅니다.
2. 프로젝트 관리창에서 `폴더 추가`를 눌러 첫 폴더를 연결합니다. 더 연결하려면 같은 `폴더 추가`를 다시 누릅니다. 연결이 끝나면 관리창을 닫습니다.
3. `로그`에서 파일을 선택합니다. 원문을 확인하면서 줄 왼쪽의 근거 표시를 눌러 판정 근거를 지정하고, `결과`에서 판정을 선택합니다. 필요한 경우 `분석 규칙 저장`을 사용합니다.
4. 검색이 필요하면 `현재 로그 찾기`, `열린 탭 찾기`, `전체 로그 찾기` 중 하나를 선택하고 `검색어 입력`에 입력합니다. 새 검색어를 입력한 뒤 첫 `Enter`는 결과 1을 포커스·표시하고, 이후 `Enter`는 다음 결과, `Shift+Enter`는 이전 결과로 이동합니다. 검색 범위는 검색창의 선택 상자에서도 바꿀 수 있습니다.
5. 선택 사항으로 `Agent 열기`를 누르거나 `Ctrl+J` / macOS `Cmd+J`를 누릅니다. `분석 시작`을 누르고, 질문이 표시되면 선택지를 고르거나 `짧은 메시지 입력`에 내용을 입력합니다. `후보 결과`를 원문과 비교한 뒤 `확인하고 저장` 또는 `거절`을 누릅니다. `취소`는 실행 중인 분석을 중지합니다.
6. 왼쪽 메뉴에서 `결과`를 열어 결과와 검토 상태를 확인합니다. `파일명, 폴더, 조건 검색`, `FAIL 모아보기`, `미확인·검토필요`, `초기화`로 범위를 조정합니다. `결과 정리`에서는 `현재 범위 추세 요약`을 확인하고, `N × M 패턴 그리드`의 `값`, `행축`, `열축`, `결과`, `폴더` 필터를 설정한 뒤 `레이아웃 저장`을 누릅니다.
7. 결과를 파일로 남기려면 `결과`에서 필요하면 `열 선택`으로 `내보낼 열`을 정하고, `CSV` 또는 `TSV 복사`를 누릅니다. `CSV 내보내기 확인` 또는 `TSV 내보내기 확인`에서 행·열 수와 미리보기를 확인하고 `확정`을 누릅니다. 중단하려면 `취소`를 누릅니다.

## 느린 LLM 응답

LLM을 사용하는 경우 응답이 느려도 로컬 검색과 파싱은 계속됩니다. Mini Agent에는 `대기`, 실행 단계, `취소`가 표시되고, 제한 시간 초과나 호출 제한은 상태와 오류로 확인할 수 있습니다. 6,000~7,000줄 로그 전체를 한 번에 업로드하지 않고, 필요한 검색·줄 범위·정보 확인 결과만 제한적으로 사용합니다.

## 꼭 필요한 단축키

- `Ctrl+F` / macOS `⌘F`: `현재 로그 찾기`
- `Ctrl+Alt+F` / macOS `⌘⌥F`: `열린 탭 찾기`
- `Ctrl+Shift+F` / macOS `⌘⇧F`: `전체 로그 찾기`
- 새 검색어 입력 후 첫 `Enter`: 결과 1 포커스·표시; 이후 `Enter`: 다음 결과; `Shift+Enter`: 이전 결과
- `F3` / `Shift+F3`: 다음 / 이전 검색 결과
- `Esc`: 검색 닫기
- `Ctrl+J` / macOS `⌘J`: `Agent 열기` 또는 Agent 패널 닫기

검색·판정·결과 정리는 로컬에서 결정적으로 실행됩니다. LLM 후보는 `확인하고 저장`을 눌렀을 때만 프로젝트 판정에 반영됩니다.
