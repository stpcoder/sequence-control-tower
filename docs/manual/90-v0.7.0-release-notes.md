# Sequence Control Tower v0.7.0

v0.7.0은 프로젝트 단위 반복 분석과 결과 검토를 보강한 릴리스입니다.

## 변경 사항

- 프로젝트 라이브러리, 새 프로젝트 초기화, 프로젝트별 폴더 연결
- 제한된 Mini Agent의 검색·줄 범위·정보 확인 도구 호출
- 느린 LLM의 대기 상태와 timeout을 표시하고 로컬 분석은 계속 수행
- 검색창에서 `Enter`를 눌렀을 때 포커스와 첫 결과 이동을 안정화
- 로그·원문·판정 3개 작업 영역의 너비 조절
- N × M 결과 레이아웃과 필터를 프로젝트에 저장
- 현재 범위의 결과 추세 요약
- Agent 후보와 판정 변경은 사람의 확인 후에만 저장
