# 분석 규칙

## 규칙 만들기

1. 로그에서 `Ctrl+F`로 판정에 사용할 문자열 또는 정규식을 검색합니다.
2. 결과를 선택합니다.
3. `분석 규칙`에서 사용할 검색을 선택합니다.
4. 발생 개수와 검색 대상을 확인합니다.
5. 순서가 중요하면 `위쪽 순서 설정`에서 순서를 지정합니다.
6. 규칙을 저장합니다.

![분석 규칙](./images/03-analysis-rule.jpg)

## 사용할 수 있는 조건

- 문자열 또는 정규식
- 대소문자 구분
- 본문 또는 파일명 검사
- 0개, 1개 이상, 정확히 N개
- 여러 marker의 출현 순서
- 반드시 포함 또는 반드시 제외

## 여러 로그에 적용

`이번 분석`에서 적용할 규칙을 선택합니다. 적용 전 미리보기에서 판정 결과와 예외를 확인합니다. 규칙 충돌, 근거 누락, 안전하지 않은 경로는 자동 확정하지 않고 검토 대상으로 남깁니다.

규칙은 프로젝트 revision으로 저장됩니다. 수정하면 새 revision이 만들어지며 이전 revision은 보관할 수 있습니다.
