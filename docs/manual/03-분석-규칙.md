# 분석 규칙

## 규칙 만들기

1. 로그에서 `Ctrl+F`로 판정에 사용할 문자열 또는 정규식을 검색합니다.
2. 결과를 선택합니다.
3. `검색 절차 저장`을 확인한 뒤 `판정 규칙 만들기`를 누릅니다.
4. `판정 규칙`에서 사용할 검색을 선택합니다.
5. 발생 개수와 검색 대상을 확인합니다.
6. 순서가 중요하면 `위쪽 순서 설정`에서 순서를 지정합니다.
7. 규칙을 저장합니다.

![분석 규칙](./images/03-analysis-rule.jpg)

## 사용할 수 있는 조건

- 문자열 또는 정규식
- 대소문자 구분
- 본문 또는 파일명 검사
- 0개, 1개 이상, 정확히 N개
- 여러 marker의 출현 순서
- 반드시 포함 또는 반드시 제외

## 여러 로그에 적용

`현재 폴더에 미리 적용`으로 편집 중인 규칙 하나를 현재 평가 폴더의 로그에만 로컬 계산합니다. 다른 평가 폴더의 규칙과 로그는 섞이지 않습니다. 미리보기에서 판정 결과와 예외를 확인하며, 규칙 충돌과 근거 누락은 자동 확정하지 않습니다.

저장 규칙에는 규칙을 만든 평가 폴더 이름이 함께 표시됩니다. 다른 평가에 재사용할 때 `불러와서 수정`을 누르고 검색어, 발생 조건, 순서를 현재 폴더에 맞게 바꾼 뒤 미리 적용합니다. 수정본은 새 revision으로 저장됩니다.

규칙은 프로젝트 revision으로 저장됩니다. 수정하면 새 revision이 만들어지며 이전 revision은 보관할 수 있습니다.
