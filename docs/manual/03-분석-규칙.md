# 분석 규칙

## 평가 폴더에 규칙 적용하기

1. 로그에서 `Ctrl+F`로 판정에 사용할 문자열 또는 정규식을 검색합니다.
2. `이 로그 판정`에서 결과를 선택합니다. 이 선택은 현재 로그의 수동 판정입니다.
3. `현재 폴더에 적용`을 누르면 검색 조건이 규칙으로 저장되고 **현재 평가 폴더 전체**를 검사합니다. 기존에 적용한 다른 규칙은 유지합니다.
4. 조건을 조정할 때는 `규칙 편집`을 엽니다. 검색 선택, 출현 횟수, 순서를 변경하고 `변경 적용`을 누릅니다.

오른쪽 `평가 폴더`와 `적용 규칙 N개`로 적용 범위를 확인합니다. 적용 후에도 적용·편집 버튼은 유지되므로 새 검색으로 규칙을 추가할 수 있습니다. 검사와 저장 중에는 같은 작업을 중복 실행할 수 없습니다.

## 사용할 수 있는 조건

- 문자열 또는 정규식
- 대소문자 구분
- 본문 또는 파일명 검사
- 0개, 1개 이상, 정확히 N개
- 여러 marker의 출현 순서
- 반드시 포함 또는 반드시 제외

발생 개수와 순서는 검색 조건별로 설정합니다. 정규식과 검색 대상을 바꿀 때는 `세부 설정`을 엽니다.

## 적용·해제·삭제 구분

`규칙 관리`에는 프로젝트에 저장한 규칙과 현재 폴더의 적용 상태가 표시됩니다.

| 동작 | 범위와 결과 |
| --- | --- |
| `이 폴더에 적용` | 현재 폴더의 기존 규칙에 추가하고 폴더 전체를 검사합니다. |
| `이 폴더에서 해제` | 이 폴더에서만 규칙을 제외하고 남은 규칙으로 다시 검사합니다. 다른 폴더와 수동 판정은 유지합니다. |
| `규칙 편집` | 프로젝트에 저장한 규칙의 조건을 수정합니다. 다른 폴더에서 이 규칙으로 판정한 결과에는 재검사가 필요합니다. |
| `프로젝트에서 삭제` | 확인 후 프로젝트 규칙을 삭제합니다. 사용하던 폴더의 이전 자동 판정은 재검사 대상으로 바뀝니다. |
| `폴더 재검사` | 현재 폴더에 적용한 최신 규칙으로 다시 검사합니다. 새로 추가된 로그도 포함합니다. |
| `수동 판정 취소` | 이 로그의 수동 판정을 취소하고 현재 폴더의 규칙으로 재검사합니다. `미확인`으로 수동 판정하는 것과 다릅니다. |

규칙 조건이 바뀌거나 삭제되면 이전 PASS/FAIL을 최신 결과처럼 사용하지 않습니다. 화면에 재검사 필요를 표시하고 자동 판정은 `미확인`으로 돌아갑니다. 직접 저장한 수동 판정은 보존합니다. 마지막 규칙까지 해제한 경우, 수동 판정이 없는 로그는 `확인 필요`로 남습니다.

규칙 미일치, 규칙 충돌, 검사 오류는 `확인 필요`로 표시합니다. 수동 판정과 다른 규칙 결과가 충돌하면 수동 판정을 덮어쓰지 않고 검토 이유를 보여 줍니다. 결과 화면의 `확인 필요만` 필터에서 후속 검토할 수 있습니다.

규칙 수정과 수동 판정 취소 이력은 내부에 보관합니다. 화면에는 최신 규칙과 현재 유효한 판정만 표시합니다.

## Agent에서 기존 조건 수정

Agent에 현재 규칙의 변경을 요청하면 기존 조건을 읽은 뒤 수정 전후를 제시합니다. `규칙 수정 저장`은 새 규칙 버전을 저장하며, 실제 판정 갱신은 해당 폴더를 재평가한 뒤 이루어집니다. 다른 곳에서 규칙을 수정하거나 삭제했다면 오래된 제안으로 덮어쓰지 않습니다. 같은 규칙을 여러 폴더에서 쓰면 수정 내용이 함께 반영됩니다.
