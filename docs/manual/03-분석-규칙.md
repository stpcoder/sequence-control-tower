# 분석 규칙

## 규칙 만들기

1. 로그에서 `Ctrl+F`로 판정에 사용할 문자열 또는 정규식을 검색합니다.
2. 결과를 선택합니다.
3. `검색 절차 저장`을 확인한 뒤 `판정 규칙 만들기`를 누릅니다.
4. `판정 규칙`에서 사용할 검색을 선택합니다.
5. 발생 개수와 검색 대상을 확인합니다.
6. 순서가 중요하면 `판정 순서`에서 먼저 나타날 조건부터 정렬합니다.
7. `저장하고 현재 폴더 적용`을 누릅니다.

![분석 규칙](./images/03-analysis-rule.jpg)

## 사용할 수 있는 조건

- 문자열 또는 정규식
- 대소문자 구분
- 본문 또는 파일명 검사
- 0개, 1개 이상, 정확히 N개
- 여러 marker의 출현 순서
- 반드시 포함 또는 반드시 제외

## 여러 로그에 적용

규칙을 저장하면 같은 평가 폴더에 저장된 기존 규칙과 함께 즉시 다시 계산됩니다. `규칙 적용 완료`에서 결과 후보와 예외 수를 확인합니다. `매핑되지 않은 로그 확인`을 누르면 규칙이 맞지 않은 로그만 모아 볼 수 있습니다. 규칙 충돌과 근거 누락은 엔지니어 판정으로 자동 확정하지 않습니다.

오른쪽 위 `규칙`을 누르면 저장 규칙 목록이 열립니다. `현재 폴더 규칙 모두 적용`으로 이 폴더에서 만든 규칙을 한 번에 다시 실행할 수 있습니다. 각 규칙의 `적용`, `수정`, `삭제`를 바로 사용할 수 있습니다. 다른 평가에 재사용할 때는 `수정`을 누르고 검색어, 발생 조건, 순서를 현재 폴더에 맞게 바꾼 뒤 저장합니다.

규칙은 프로젝트 revision으로 저장되며 수정할 때 새 revision이 만들어집니다.
