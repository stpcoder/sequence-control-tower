# 분석 규칙

## 규칙 만들기

1. 로그에서 `Ctrl+F`로 판정에 사용할 문자열 또는 정규식을 검색합니다.
2. 결과를 선택합니다.
3. `검색 절차 저장`을 확인한 뒤 `판정 규칙 만들기`를 누릅니다.
4. `판정 규칙`에서 사용할 검색을 선택합니다.
5. 발생 개수와 검색 대상을 확인합니다.
6. 순서가 중요하면 `판정 순서`에서 먼저 나타날 조건부터 정렬합니다.
7. `저장하고 현재 폴더 적용`을 누릅니다.

![분석 규칙](./images/03-analysis-rule.jpg)

## 사용할 수 있는 조건

- 문자열 또는 정규식
- 대소문자 구분
- 본문 또는 파일명 검사
- 0개, 1개 이상, 정확히 N개
- 여러 marker의 출현 순서
- 반드시 포함 또는 반드시 제외

## 여러 로그에 적용

규칙을 저장하면 현재 평가에 적용 중인 기존 규칙에 추가되고 폴더 전체를 즉시 분류합니다. 한 규칙과 일치하면 해당 결과가 바로 적용됩니다. 아무 규칙도 일치하지 않거나 서로 다른 결과의 규칙이 동시에 일치하면 `예외`로 남습니다. 사람이 직접 저장한 판정은 규칙 결과로 덮어쓰지 않습니다.

오른쪽 위 `규칙`을 누르면 저장 규칙 목록이 열립니다. `추가`를 누르면 선택한 규칙이 현재 평가의 규칙 집합에 더해집니다. 기존 규칙은 유지됩니다. `다시 분류`는 현재 적용 중인 전체 규칙을 새로 추가된 로그까지 다시 실행합니다. `수정`은 새 revision을 저장하고, `삭제`는 저장 규칙과 해당 규칙의 적용 결과를 제거합니다.

규칙은 프로젝트 revision으로 저장되며 수정할 때 새 revision이 만들어집니다.
