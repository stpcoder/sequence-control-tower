# 결과 정리와 내보내기

## 결과 확인

`결과`에서 로그별 판정, 조건 후보, 진행 단계, 검토 상태를 확인합니다. 평가 폴더를 선택하면 해당 평가의 로그만 표시됩니다.

![결과 화면](./images/04-results.jpg)

파일명에서 추출한 온도, Mode, 자재(Sample), SKEW 후보는 승인하거나 수정할 수 있습니다. 이 시스템에서 자재와 Sample은 같은 값이며 별도 항목으로 계산하지 않습니다. 엔지니어가 확정한 값은 자동 추출 결과보다 우선합니다.

다음 위치형 파일명은 구분자 순서대로 읽습니다.

`..._Ch8_SM8975_1_25_1.00_EVA_EN_DEFAULT_5333MHZ_COM74_DHCST-89_C_Pass.log`

| 값 | 의미 |
| --- | --- |
| `Ch8` | 실장기 채널 |
| `SM8975` | SoC |
| `1` | 평가 번호/Grid 후보 |
| `25`, `1.00` | 온도, VDD |
| `EN` | ECC |
| `DEFAULT_5333MHZ` | 사용자 조건과 주파수 |
| `COM74` | PC 포트로 분석에서 제외 |
| `DHCST-89` | 자재(Sample) |
| `C` | 평가 Step |
| `Pass` | 결과 |

파일명의 `Ch8`은 실장기 채널입니다. 로그 본문의 Hdiag Fail address `Channel`과 따로 저장합니다. `EVA`는 내부 구분값으로 분석 축에서 제외합니다.

`진행 단계`는 SoC에 맞춰 Training, UEFI 또는 LK, OS, 테스트를 구분합니다. Training fail, 테스트 중 Halt, Reboot도 발생 단계와 함께 표시합니다.

## 분석 보기 선택

1. `결과 정리`를 엽니다.
2. `분석 보기`에서 목적을 선택합니다.
3. `평가 결과` 또는 `Fail 주소`를 선택합니다.
4. 표시 값과 시각화를 선택합니다.
5. 필요한 경우 평가 폴더와 결과를 필터링합니다.
6. `왼쪽 축`과 `상단 축`에 조건을 배치합니다.

![결과 정리](./images/05-results-summary.jpg)

자주 사용하는 분석 보기는 다음과 같습니다.

| 분석 보기 | 확인 내용 |
| --- | --- |
| `조건별 판정` | Sample과 SKEW별 PASS/FAIL을 비교합니다. |
| `재현 비교` | 같은 Sample의 반복 평가에서 불량이 재현되는지 확인합니다. |
| `가속 조건` | 온도, VDD, 주파수 조건별 불량률을 비교합니다. |
| `TM 개선 비교` | Test Mode 적용 전후의 PASS/FAIL을 비교합니다. |
| `4-Corner 비교` | Hot/Cold와 High/Low VDD 조합을 비교합니다. |
| `DQ · BL 집중` | 로그 본문의 Fail address를 DQ×BL Heatmap으로 확인합니다. |
| `Bank · DQ 집중` | Bank와 DQ에 Fail address가 집중되는지 확인합니다. |

## 평가 결과와 Fail 주소

`평가 결과`는 로그별 최종 판정과 조건을 사용합니다.

- `판정 결과`: `PASS`, `FAIL`, `PASS 2 · FAIL 1`로 표시합니다.
- `FAIL 횟수`: Training Fail, Test Fail, Halt, Reboot를 포함한 실패 판정 수입니다.
- `불량률`: `FAIL / (PASS + FAIL)`입니다. 미확인 결과는 분모에서 제외합니다.

`Fail 주소`는 로그 본문의 Hdiag fail 또는 miscompare 주소를 사용합니다. 파일명에 있는 DQ, BL 후보를 Fail address로 계산하지 않습니다.

- `이벤트 수`: Fail address가 기록된 횟수입니다.
- `포함 로그 수`: 해당 주소 이벤트가 나온 로그 수입니다.
- `이벤트 비율`: 전체 Fail address 이벤트 중 선택한 셀의 비율입니다.

Heatmap 셀에는 `FAIL 3 · DQ 0 · BL 0` 또는 `12회 · DQ 0 · BL 0`처럼 판정과 대표 주소를 표시합니다. Channel, Sub Channel, CS, Rank, Bank Group, Bank, Row, Column, DQ, BL, WR, RD를 축으로 사용할 수 있습니다.

## 조건 배치와 선택

`왼쪽 축`과 `상단 축`에는 각각 최대 3개 항목을 배치할 수 있습니다. 항목을 끌어 순서를 바꾸거나 `축 바꾸기`로 두 방향을 교환합니다.

표의 셀이나 차트 항목을 선택하면 바로 아래에 선택 범위가 표시됩니다.

- PASS/FAIL 판정 수
- 주요 DQ, BL, Channel, Bank 주소
- 선택 해제
- 선택 CSV
- Agent 분석

선택한 상태에서 `Agent 분석`을 누르면 Agent가 같은 평가 폴더의 로그를 로컬 도구로 다시 계산합니다. 화면의 숫자만 복사해 답하지 않습니다.

## 시각화

- `교차표`: 조건별 판정과 숫자를 정확히 확인합니다.
- `Heatmap`: Temp×VDD, DQ×BL, Bank×DQ의 집중 위치를 확인합니다.
- `세로 막대`, `가로 막대`: 조건별 순위를 비교합니다.
- `PASS/FAIL 구성`: 조건별 PASS와 FAIL 판정 수를 비교합니다.
- `PASS/FAIL 비율`: Sample 수가 다른 조건을 같은 비율로 비교합니다.
- `조건 변화`: VDD, 온도, 주파수처럼 순서가 있는 조건을 비교합니다.
- `건수와 비율`: FAIL 횟수와 불량률을 함께 확인합니다.

## 공유

상단의 `공유`에서 저장 형식을 선택합니다.

![공유 메뉴](./images/11-result-sharing.jpg)

| 기능 | 저장 내용 |
| --- | --- |
| `표 복사` | 현재 표를 Excel, 메신저, 문서에 붙여넣습니다. |
| `현재 표 CSV` | 현재 왼쪽·상단 축과 합계를 저장합니다. |
| `현재 시각화 PNG` | 현재 차트를 이미지로 저장합니다. |
| `선택 로그 CSV` | 선택한 셀에 포함된 로그만 저장합니다. |
| `Fail 주소 CSV` | Fail address 이벤트를 한 행씩 저장합니다. 조건, 원본 로그, 줄 번호, Channel, Sub Channel, CS, Rank, BG, Bank, Row, Column, DQ, BL, WR, RD를 포함합니다. |
| `평가 결과 CSV` | 로그 한 건을 한 행으로 저장합니다. 판정과 평가 조건을 포함합니다. |

보고서 표에는 `현재 표 CSV`, 불량 주소 분석에는 `Fail 주소 CSV`, 추가 가공에는 `평가 결과 CSV`를 사용합니다. 원본 로그 파일은 변경되지 않습니다.

## 로그별 결과 내보내기

`결과` 화면의 `열 선택`에서 판정, 평가 조건, 파일 정보를 선택합니다. 선택한 열은 프로젝트 기본값으로 저장됩니다. `판정 근거 열`을 켜면 자동 판정과 엔지니어가 선택한 근거 수를 함께 내보냅니다. Excel에는 `TSV 복사`, 파일 공유에는 `CSV`를 사용합니다.
