# Sequence Control Tower 시작하기

이 문서는 Sequence Control Tower의 첫 실행부터 첫 로그 판정까지 안내합니다. 설치 파일과 Windows 시작 메뉴에는 `Sequence Control Tower`로 표시됩니다.

Sequence Control Tower는 선택한 폴더의 로그 파일을 등록하고, 원문 검색, 판정 근거 표시, 결과 저장, 규칙 저장, 일괄 확인을 제공합니다. 폴더 등록과 검색은 이 PC에서 실행됩니다. 원본 로그 파일은 읽기 전용으로 열립니다.

설치 방법은 운영체제별 문서를 먼저 확인하세요.

- [Windows 설치 및 제거](windows-installation.md)
- [macOS 설치](macos-installation.md)

## 첫 실행

### Windows에서 열기

- 설치형: 시작 메뉴 또는 바탕 화면에서 `Sequence Control Tower`를 실행합니다.
- Portable EXE: `Sequence-Control-Tower-Portable.exe`를 실행합니다.
- Portable ZIP: 압축을 푼 폴더에서 `Sequence Control Tower.exe`를 실행합니다.

Windows 지원 환경은 Windows 10/11 x64입니다.

### macOS에서 열기

1. `Applications` 폴더를 엽니다.
2. `Sequence Control Tower`를 실행합니다.
3. Gatekeeper 창이 표시되면 Applications에서 앱을 Control-클릭하고 `열기`를 선택합니다.
4. 확인 창에서 `열기`를 선택합니다.

macOS 지원 환경은 macOS 12 Monterey 이상입니다. 차단 안내가 계속되면 macOS 12에서는 `시스템 환경설정 > 보안 및 개인 정보 보호`, macOS 13 이상에서는 `시스템 설정 > 개인정보 보호 및 보안`에서 해당 앱 안내를 확인하세요.

### 처음 보이는 화면

앱은 왼쪽 메뉴의 `로그` 화면에서 시작합니다. 로그를 등록하지 않은 상태에는 가운데에 `분석할 로그 폴더를 추가하세요.`가 표시됩니다.

상단 바에는 다음 항목이 있습니다.

| 화면에 표시되는 항목 | 동작 |
|---|---|
| `Local engine ready` | 로컬 분석 엔진 상태를 표시합니다. |
| `도움말` | 도움말 버튼입니다. |
| `알림` | 알림 버튼입니다. |
| `Sequence 가져오기` | 폴더를 선택해 로그를 등록합니다. |

`Sequence 가져오기`와 `로그` 화면의 `로그 폴더 열기`는 동일한 폴더 가져오기 동작을 실행합니다.

## 첫 폴더 선택

1. `로그` 화면에서 `로그 폴더 열기` 또는 상단의 `Sequence 가져오기`를 누릅니다.
2. 폴더 선택 창의 제목 `분석할 로그 폴더 선택`을 확인합니다.
3. 로그가 들어 있는 폴더를 선택합니다. Windows에서는 `폴더 선택`(영문 UI `Select Folder`), macOS에서는 `선택`(영문 UI `Choose`)을 눌러 확정합니다. 여러 폴더를 선택할 수 있습니다.
4. 선택한 폴더의 하위 폴더까지 검색됩니다.
5. 확장자가 `.log`인 파일이 등록됩니다. 한 번의 가져오기는 최대 10,000개 파일까지 처리합니다.
6. 왼쪽 목록에 폴더 이름과 파일 수가 나타나면 파일 이름을 누릅니다.

등록 완료 후 알림에는 가져온 로그 수가 표시됩니다. 일부 파일을 처리하지 못하면 실패 수, 제외 수, 10,000개 제한 도달 여부가 함께 표시됩니다.

폴더를 선택하면 로그의 메타데이터가 등록되고, 선택한 로그를 열 때 원문을 읽습니다. 원본 파일의 내용은 수정하지 않습니다. 동일 내용의 파일은 SHA-256으로 관리되며 각 파일의 출처와 상대 경로가 유지됩니다.

## 화면 이름과 주요 조작

### `로그`

로그 파일을 열고 검색하고 판정합니다.

- 왼쪽 목록: 등록된 폴더, 파일, 검색 결과, 예외 로그
- 가운데: 읽기 전용 원문, 검색 결과, 줄 번호
- 오른쪽 `판정`: 결과 선택, 원문 북마크, 분석 규칙
- `로그 폴더 열기`: 폴더를 추가합니다.
- `모든 로그 검색`: 등록된 로그 전체에서 검색합니다.
- `현재 로그 찾기`: 선택한 로그에서 검색합니다.
- `전체 로그 찾기`: 등록된 모든 로그에서 검색합니다.
- `검색 옵션`: `대/소문자 구분`, `단어 단위 일치`, `정규식 사용`
- 줄 왼쪽의 원형 버튼: `판정 근거 표시`
- `결과`: `Pass`, `Diag fail`, `Test fail`, `Training fail`, `System halt`, `System reboot`, `Incomplete`, `Unknown`, `Excluded`
- `원문 북마크`: 표시한 근거 줄 목록입니다.
- `분석 규칙 저장`: 선택한 검색 근거로 규칙 패널을 엽니다.
- `규칙 저장`: 분석 규칙을 저장합니다.
- `전체에 미리 적용`: 저장할 규칙을 모든 로그에 계산합니다.
- `예외 N개 확인`: 일괄 계산에서 확인이 필요한 로그를 엽니다. `N`은 실제 예외 개수로 표시됩니다.

검색 결과를 선택한 뒤 `Enter`로 다음 결과, `Shift+Enter`로 이전 결과로 이동합니다. `F3`은 다음 결과, `Shift+F3`은 이전 결과입니다. `Esc`는 검색을 닫습니다.

### `결과표`

등록된 로그의 메타데이터 후보, 결과, 검토 상태, 근거 수를 표로 확인합니다.

- 상단 버튼: `TSV 복사`, `CSV`
- 검색 입력 안내: `파일명, 폴더, 조건 검색`
- 필터: `결과`, `검토`
- 필터 값: `전체`, `검토 필요`, `확정`
- `초기화`: 검색과 필터를 지웁니다.
- 열 이름: `파일명`, `폴더`, `Sample`, `온도`, `Mode`, `결과`, `판정 검토`, `근거`
- 페이지 이동: `이전`, `다음`

`Sample`, `온도`, `Mode`에 표시된 후보 값을 누르면 `승인` 상태로 저장됩니다. 파일명과 원문을 확인한 뒤 승인하세요. [로그 분석 작업](00-log-workbench.md)에서 결과표와 내보내기 절차를 확인할 수 있습니다.

### `패턴`

결과 수와 조건별 분포를 확인합니다.

- `결과 분포`: 결과별 로그 수를 표시합니다.
- `조건별 결과`: 축을 선택해 결과를 집계합니다.
- 축 선택 값: `Sample`, `온도`, `Mode`
- `선택 로그`: 선택한 결과와 조건에 해당하는 로그를 표시합니다.
- `선택 해제`: 결과 분포 또는 조건 선택을 지웁니다.

표의 로그 행을 누르면 해당 파일이 `로그` 화면에서 열립니다.

### `설정`

화면 제목은 `LLM 연결`입니다. 사내 OpenAI-compatible API를 연결할 때 사용합니다. 연결하지 않은 상태에서는 `로컬 규칙 엔진 사용 중`이 표시됩니다.

- 입력 항목: `Base URL`, `Model`, `API key`
- `지우기`: 입력한 API key를 지웁니다.
- `모델 목록 확인`: Gateway에서 사용할 모델 목록을 확인합니다.
- 구역: `호출 제한`, `로컬 분석`
- 호출 제한 항목: `RPM`, `TPM`, `Timeout`, `Retries`
- `저장`: 설정을 저장합니다.
- 저장 완료 상태: `저장됨`

`로컬 분석`에는 `로그 검색 · 정규식`, `판정 규칙 · 근거 줄`, `결과표 · 패턴 집계`가 표시됩니다.

## 메뉴와 단축키

### Windows

Windows에는 앱 메뉴가 표시되지 않습니다. 다음 단축키를 앱 창에서 사용할 수 있습니다.

| 동작 | 단축키 |
|---|---|
| 로그 폴더 열기 | `Ctrl+O` |
| 현재 로그 찾기 | `Ctrl+F` |
| 전체 로그 찾기 | `Ctrl+Shift+F` |
| 설정 열기 | `Ctrl+,` |
| 검색 다음 결과 | `Enter` 또는 `F3` |
| 검색 이전 결과 | `Shift+Enter` 또는 `Shift+F3` |
| 검색 닫기 | `Esc` |

### macOS

macOS 상단 메뉴에서 다음 항목을 사용할 수 있습니다.

- 앱 메뉴 `Sequence Control Tower` > `Settings…`
- `File` > `Open Logs…`
- `Edit` > `Find` > `Find…`
- `Edit` > `Find` > `Find in Logs…`

| 동작 | 단축키 |
|---|---|
| 로그 폴더 열기 | `⌘O` |
| 현재 로그 찾기 | `⌘F` |
| 전체 로그 찾기 | `⌘⇧F` |
| 설정 열기 | `⌘,` |
| 검색 다음 결과 | `Enter` 또는 `F3` |
| 검색 이전 결과 | `⇧Enter` 또는 `⇧F3` |
| 검색 닫기 | `Esc` |

`View` 메뉴에는 `Reset Zoom`, `Zoom In`, `Zoom Out`, `Toggle Fullscreen`이 있습니다. `Window` 메뉴에는 `Minimize`, `Zoom`, `Bring All to Front`가 있습니다. 개발 빌드에서는 `Reload`, `Toggle Developer Tools`가 추가됩니다.

## 로컬 저장 데이터

데스크톱 앱은 사용자 데이터 폴더에 로그와 분석 상태를 저장합니다.

### Windows 경로

```text
%APPDATA%\Sequence Control Tower\sequence-intelligence
```

### macOS 경로

```text
~/Library/Application Support/Sequence Control Tower/sequence-intelligence
```

저장되는 항목은 다음과 같습니다.

- 가져온 로그의 로컬 사본과 파일 출처 메타데이터
- 검색 근거, 엔지니어 판정, 분석 규칙, 일괄 판정 결과
- `Base URL`, `Model`, 호출 제한 설정
- 분석 캐시와 위키 데이터

API key는 설정 방식과 OS 암호화 지원 상태에 따라 암호화 저장되거나 현재 세션에 유지될 수 있습니다. 원본 로그를 이동하거나 삭제해도 앱에 등록된 로컬 데이터는 자동으로 지워지지 않습니다. 지원이 필요하면 앱을 종료하고 위 운영체제별 경로의 `sequence-intelligence` 폴더를 먼저 다른 위치에 복사해 백업하세요. 폴더를 삭제하거나 이름을 바꾸지 말고, 백업 경로·앱 버전·문제 발생 시각을 사내 IT 또는 Sequence Control Tower 지원 담당자에게 전달해 확인을 요청하세요.

## 10분 첫 작업

### 0–1분: 앱 열기

운영체제에 맞게 앱을 열고 왼쪽 메뉴에서 `로그`를 확인합니다.

### 1–3분: 폴더 등록

`로그 폴더 열기`를 누르고 `분석할 로그 폴더 선택` 창에서 테스트할 로그 폴더 하나를 선택합니다. 왼쪽 폴더 목록에 파일이 나타나는지 확인합니다.

### 3–5분: 원문 열기

왼쪽 폴더를 펼치고 `.log` 파일 이름을 누릅니다. 가운데 원문에서 파일명과 상대 경로를 확인합니다. `현재 로그 찾기`를 누르고 검색어를 입력합니다.

### 5–7분: 검색 근거 표시

검색 결과가 있는지 확인합니다. 판정에 사용할 줄의 왼쪽 원형 버튼을 누릅니다. 오른쪽 `원문 북마크`에 `Ln N` 항목이 생기는지 확인합니다. `N`은 실제 로그 줄 번호로 표시됩니다.

검색 조건을 바꿀 때는 `검색 옵션`에서 필요한 항목만 선택합니다.

### 7–8분: 결과 저장

오른쪽 `판정`의 `결과`에서 하나를 선택합니다. 선택 값은 `Pass`, `Diag fail`, `Test fail`, `Training fail`, `System halt`, `System reboot`, `Incomplete`, `Unknown`, `Excluded`입니다. 기존 판정이 있는 파일의 값을 바꾸면 `기존 ... → ... 변경 확정` 버튼을 눌러 새 revision을 저장합니다.

### 8–10분: 결과표 확인

왼쪽 메뉴에서 `결과표`를 누릅니다. `파일명`, `Sample`, `온도`, `Mode`, `결과`, `판정 검토`, `근거`를 확인합니다. 필요한 후보 값을 눌러 승인하고, 결과를 전달할 때 `TSV 복사` 또는 `CSV`를 누릅니다.

작업 결과를 조건별로 확인하려면 `패턴`에서 `결과 분포`와 `조건별 결과`의 축을 선택합니다. 세부 판정 절차는 [로그 분석 작업](00-log-workbench.md)을, 사내 LLM 연결은 [LLM 연결](05-settings.md)을 참고하세요.
