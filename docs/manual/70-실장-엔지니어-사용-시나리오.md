# Sequence Control Tower v0.6 사용자 작업

원본 로그 파일은 읽기 전용으로 열립니다. 원문 내용과 줄 번호는 바뀌지 않습니다. 아래 단계는 현재 `로그`, `결과표`, `패턴`, `설정` 화면의 버튼명과 동작을 기준으로 합니다.

검증용 폴더는 `tests/fixtures/engineer-workflow/`와 `tests/fixtures/qualcomm-bringup/`를 사용할 수 있습니다. Qualcomm fixture의 SYN 단계는 테스트용 문자열입니다.

## 1. 검증 엔지니어: 여러 폴더 분류

### 입력과 목표

여러 로그 폴더를 등록하고 파일명 메타데이터와 결과를 확인합니다.

### 작업 순서

1. `로그`에서 `로그 폴더 열기`를 누르고 폴더를 선택합니다. Windows는 `Ctrl+O`, macOS는 `⌘O`를 사용할 수 있습니다. 등록 완료 알림의 성공·실패·제외 수를 확인합니다.
2. `결과표`에서 `파일명`, `폴더`, `Sample`, `온도`, `Mode`, `Grid` 열을 확인합니다.
3. 파일명에서 네 필드를 결정적으로 추출합니다. 값 하나는 `후보`로 검토합니다. 파일명 값이 없거나 서로 다른 후보가 충돌하는 `conflict`인 경우 결과표의 값 셀은 비어 있고 `미확인`으로 표시됩니다. 화면과 내보내기 상태는 각각 `candidate`, `missing`, `malformed`입니다.
4. 파일명에 값이 없으면 로그 본문에서 해당 필드를 찾습니다. 본문에도 값이 없거나 서로 다른 값이 여러 개면 결과표에서 `미확인`으로 표시합니다.
5. 후보 값은 값을 눌러 승인합니다. 셀을 눌러 `Sample`, `온도`, `Mode`, `Grid` 값을 직접 입력한 뒤 `저장`을 누릅니다. 직접 입력한 값은 메타데이터 승인 revision으로 저장됩니다.
6. 저장된 값은 `승인`으로 표시됩니다. `거절` 값은 재검토 대상으로 남깁니다. `미확인`은 값이 없는 상태로 승인할 수 없습니다.

### 기대 결과

파일별 `Sample`, `온도`, `Mode`, `Grid` 상태와 결과가 결과표에 표시됩니다.

### 예외 처리

등록 실패, 충돌, 미확인은 해당 파일을 열어 파일명과 원문을 확인합니다.

## 2. Bring-up/Debug 엔지니어: UEFI에서 OS까지 정지·재부팅·Training 실패 추적

### 작업 순서

1. `현재 로그 찾기`, `열린 탭 찾기`, `전체 로그 찾기` 중 범위를 선택합니다. Windows는 `Ctrl+F`, `Ctrl+Alt+F`, `Ctrl+Shift+F`, macOS는 `⌘F`, `⌘⌥F`, `⌘⇧F`를 사용할 수 있습니다. 검색 결과 수가 `0 / 0`, `1 / N`, `N / N` 형식으로 표시됩니다.
2. 검색 기록에서 판정에 사용할 항목의 pin을 누릅니다. pin된 항목은 `📌`로 표시됩니다. 다시 누르면 pin을 해제합니다.
3. 발생 조건을 선택합니다: `0개`, `1개 이상`, `정확히 N개`. `정확히 N개`를 선택하면 횟수를 입력합니다.
4. 필요하면 `위쪽 순서 설정`을 누릅니다. 순서 팝업에서 `↑`, `↓`로 조건 순서를 정하고 `이 순서 확정`을 누릅니다.
5. 결과를 선택하고 `규칙 저장`을 누릅니다. 새 저장은 revision으로 기록됩니다. `전체에 미리 적용`을 누른 뒤 `예외 N개 확인`에서 파일별 사유와 원문 위치를 확인합니다.
6. `저장 규칙`을 열어 규칙을 `현재 파일에 불러오기`로 가져옵니다. 수정 후 `규칙 저장`을 누르면 새 revision이 생성됩니다. 사용하지 않는 규칙은 `보관`을 누릅니다.

### 기대 결과

검색 기록과 규칙 revision, 판정 근거가 파일별로 보존됩니다.

### 예외 처리

검색 결과가 0개이면 검색 범위와 검색 옵션을 확인합니다. 규칙 충돌은 `예외 N개 확인`에서 원문을 확인합니다.

## 3. 리포트 오너: 행·열·근거를 선택해 CSV/TSV 만들기

### 작업 순서

위 1~2단계에서 판정과 메타데이터를 확인한 뒤 결과표를 내보냅니다.

## 4. AI 패턴 검토

1. `설정`의 `LLM 연결`에서 OpenAI-compatible vLLM의 `호출 제한`인 `RPM`, `TPM`, `Timeout`, `Retries`와 `Base URL`, `Model`, `API key`를 입력하고 `저장`을 누릅니다. `모델 목록 확인`으로 연결을 확인합니다.
2. 로그를 선택하고 오른쪽 `AI 패턴 검토`에서 `검토 메모 (선택)`을 입력합니다. `검토 실행`을 누릅니다. 진행 중에는 `검토 중`, `대기 N번`, `취소`가 표시됩니다.
3. 분석 요청에는 원문 전체를 보내지 않습니다. 로컬 deterministic parser가 만든 최소 evidence만 전송하며 실제 요청 문자열은 8,000자 이하입니다. 파일명 메타데이터, 구조 수, 제한된 fact·변경·근거 발췌를 우선순위로 선택하고 민감한 문자열을 정리합니다.
4. `검토 결과`에서 `추천 태그·검색`을 확인합니다. `메타데이터 제안`의 필드·값·이유를 확인하고 각 항목의 `적용`을 누릅니다. 적용 대상은 파일명 상태가 `unknown` 또는 `conflict`인 `Sample`, `온도`, `Mode`, `Grid`입니다.
5. AI 결과만으로 결과를 저장하지 않습니다. 원문과 근거를 확인한 뒤 `결과`를 선택하거나 `규칙 저장`을 누릅니다.

로그 원문 줄 왼쪽의 `근거 거터`를 눌러 근거를 지정합니다. 오른쪽 `원문 북마크`의 줄을 누르면 원문 위치로 이동합니다. `분석 규칙 저장`을 눌러 규칙 편집을 다시 엽니다.

## 5. N × M 패턴 확인

1. `패턴`을 엽니다. `N × M 패턴 그리드`의 `값`에서 `로그 수`, `Fail 수`, `Evidence 수` 중 집계를 선택합니다.
2. `행축`의 필수 축과 선택 축을 정합니다. 선택 축은 `보조행축` 역할을 하며 `사용 안 함`도 선택할 수 있습니다.
3. `열축`의 필수 축과 선택 축을 정합니다. 선택 축은 `보조열축` 역할을 하며 `사용 안 함`도 선택할 수 있습니다.
4. 축에는 `Sample`, `온도`, `Mode`, `Grid`, `결과`, `검토`, `폴더`, `Run`을 사용할 수 있습니다. 한 축 그룹에는 최대 두 개를 선택합니다.
5. `결과`, `폴더`, `FAIL만`, `미확인 metadata만` 필터를 적용합니다. `전체 해제`로 필터와 셀 선택을 해제합니다.
6. 셀을 누르면 해당 셀의 원본 로그가 아래 `셀의 원본 로그`에 표시됩니다. 로그 행 또는 파일명을 누르면 `로그`의 원문 위치로 이동합니다. 표시 목록은 최대 150개입니다.

## 6. 결과표, 선택, 내보내기

1. `결과표` 검색창에 `파일명, 폴더, 조건 검색`을 입력합니다. `결과`, `검토`, `폴더 범위`를 선택합니다.
2. `FAIL 모아보기`로 FAIL 결과를 모읍니다. `미확인·검토필요`로 검토 대상과 미확인 메타데이터를 모읍니다. `초기화`로 조건을 해제합니다.
3. 행 왼쪽 체크 상자로 행을 선택합니다. `필터된 행 전체 선택`은 현재 필터 결과를 선택합니다. 선택 행이 있으면 현재 필터 범위의 선택 행을 내보내고, 선택 행이 없으면 현재 필터 범위 전체를 내보냅니다. 0행이면 `TSV 복사`와 `CSV`가 비활성화됩니다.
4. `열 선택`을 누르고 `내보낼 열`을 확인합니다. 기본 열은 18개이며 `Grid 값`, `Grid 상태`를 포함합니다: `source_id`, `artifact_id`, `source_key`, `relative_path`, `run`, `filename`, `folder`, `sample_value`, `sample_state`, `temperature_value`, `temperature_state`, `mode_value`, `mode_state`, `grid_value`, `grid_state`, `result`, `result_source`, `review`.
5. 선택적으로 `근거` 그룹을 켭니다. `evidence_count`, `selected_evidence_count`가 추가됩니다.
   화면의 `근거 수`, `선택 근거 수`와 내보낸 값을 대조합니다.
6. `CSV` 또는 `TSV 복사`를 누릅니다.
7. `{형식} 내보내기 확인` 창에서 행 수·열 수·첫 5행을 확인한 뒤 내보내려면 `확정`, 중단하려면 `취소`를 누릅니다. `확정` 후 CSV는 다운로드 파일로 저장되고 TSV는 클립보드에 복사됩니다. 원본 로그 파일은 내보내기 과정에서 변경되지 않습니다.
