# Sequence Control Tower v0.9.0

## 주요 변경

- 프로젝트별 Native Agent 대화와 도구 실행 상태 영구 저장
- OpenCode headless sidecar와 Sequence Control Tower 읽기 전용 MCP 도구 연결
- OpenCode 미설치 또는 호환 오류 시 내장 Agent 자동 전환
- 느린 사내 OpenAI-compatible LLM 대기, 중지, 재시도, 앱 재시작 복구
- Qualcomm/MediaTek SoC 식별과 SoC별 Boot profile 단계 검사
- RT를 동일 Sample·Sequence의 이전 FAIL 평가와 연결하는 Attempt 모델
- SKEW, Lot, Material, Die, Sample, 온도, VDD, 주파수, Pattern, DQ, BL, Channel, Bank와 명령별 실패 경향
- 처음 확인된 명령 목적을 한 번 묻고 프로젝트·SoC 범위에 저장하는 명령 지식
- PASS, FAIL, training fail, reboot, halt, fast fail 결정 규칙 검사
- 평가 브랜치, 조건별 불량 집중도, 과거 LPDDR5/LPDDR6 유사 사례 조회
- Ctrl-F와 정규식 검색 기록을 프로젝트 Agent 문맥으로 저장
- LPDDR6 Xiaomi 16Gb VPERI 샘플 프로젝트와 LPDDR5 과거 사례 추가
- 프로젝트 폴더 ID와 artifact 원본 ID를 함께 보존하여 폴더 연결 정합성 개선

## 보안 경계

- LLM에 로그 전체와 절대경로를 전송하지 않습니다.
- OpenCode의 shell, 파일 편집, 전체 파일 읽기, 웹 도구를 차단합니다.
- MCP 도구는 loopback 주소와 임시 인증 token을 사용합니다.
- 프로젝트 수정과 평가 확정은 앱의 기존 확인 흐름을 사용합니다.

## 검증

- Windows/macOS typecheck, 전체 테스트, production build
- LPDDR6 샘플 9개 로그 import, SoC/Die 추출, RT 연결, 평가 branch와 LPDDR5 참조 생성
- marker 우선순위, 파일명 조건 추출, 검색 기록 중복 제거, 중단 세션 복구 테스트
