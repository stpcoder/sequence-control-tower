# Sequence Control Tower UI 기준

## 기준 화면

로그 화면을 제품 UI의 기준으로 사용합니다. 새 화면은 별도의 색상 체계나 카드 스타일을 만들지 않고 `src/styles.css`의 `--sct-*` 토큰을 사용합니다.

## 기본 규칙

- 배경: `--sct-bg`, 편집기: `--sct-editor`, 좌우 패널: `--sct-sidebar`
- 구분선: `--sct-line`, 입력 테두리: `--sct-line-strong`
- 입력·드롭다운: 높이 `--sct-control-height`, 배경 `--sct-control`, radius `--sct-control-radius`
- 주 동작: `--sct-blue`; PASS·FAIL·주의 색은 상태 표시에만 사용
- 페이지 헤더: 높이 56px, 본문 제목 18px
- 팝업: `--sct-popup-radius`, `--sct-sidebar` 배경
- 폼을 카드 여러 개로 감싸지 않습니다. 섹션은 여백과 한 줄 구분선으로 나눕니다.
- 설명은 현재 동작과 다음 행동에 필요한 한 문장만 표시합니다.

## 페이지별 금지 사항

- 로그 화면과 다른 임의의 초록색·민트색 주 동작
- 페이지마다 다른 드롭다운 배경·테두리·높이
- 동일한 제목·로그 개수·도움말의 반복
- 선택 상태를 과도한 좌측 막대나 큰 배경 면적으로 표현
- Agent의 내부 구현명, 도구명, 모델명을 본문 설명으로 반복

## 변경 확인

UI 변경 후 로그, 결과, 결과 정리, 평가 이력, Agent를 같은 창 크기에서 확인합니다. 드롭다운과 `details` 메뉴가 열린 상태도 캡처해 배경, 여백, 텍스트 크기, 포커스가 동일한지 비교합니다.
